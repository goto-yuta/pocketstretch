# ストレッチ画像生成 — ChatGPT DALL-E 3 プロンプトガイド

## 使い方

1. ChatGPTで **新しい会話** を開く
2. 最初のメッセージに **スタイル設定プロンプト** を貼る
3. その後、各ストレッチのプロンプトを1つずつ送信
4. 生成された画像を **ファイル名の指示通り** に保存
5. すべて保存したら `assets/stretches/` フォルダに入れる

---

## スタイル設定プロンプト（最初に1回だけ貼る）

```
これからストレッチアプリ用のイラストを順番に生成してほしい。
毎回必ず以下のスタイルを守ること：

【スタイル】
- フラットイラスト、ベクター風
- 背景：クリーム白（#FAF7F4）
- 人物：シンプルな性別不明のシルエット、テラコッタ〜ウォームブラウンの温かみのある色
- シャドウなし、テキストなし
- 余白を多めに取ったスクエア構図（1:1）
- フィットネス・ウェルネスアプリに適したクリーンでミニマルなデザイン

了解したら「了解しました」と答えてから、次の指示を待って。
```
